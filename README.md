# Chrono | Premium Stopwatch

A modern, high-precision stopwatch web application built with HTML, CSS, and JavaScript.

## Features

- **High Precision Timing**: Tracks time down to milliseconds.
- **Lap Functionality**: Record multiple laps with split times.
- **Modern UI**: Sleek, responsive design with glassmorphism effects.
- **Keyboard Support**: Spacebar to Start/Stop.

## Technologies Used

- HTML5
- CSS3 (Custom Variables, Flexbox, Glassmorphism)
- JavaScript (ES6+ Classes)

## How to Run

1. Clone the repository.
2. Open `index.html` in your browser.
